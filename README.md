# SQL Avançado — UFCD 0814

Tutorial interativo de SQL avançado, com conteúdos, exemplos e exercícios para MySQL/MariaDB.

## Publicação no GitHub Pages

1. Crie um repositório público no GitHub.
2. Envie **o conteúdo desta pasta para a raiz do repositório**, incluindo `index.html`, `app.js`, `lessons.js`, `style.css` e `.nojekyll`.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, branch **main** e pasta **/(root)**. Guarde.
5. O site ficará em `https://UTILIZADOR.github.io/NOME-DO-REPOSITORIO/` após a publicação.

Não necessita de Node.js, compilação ou backend. O progresso das lições é guardado no armazenamento local do navegador. A execução dos exemplos SQL requer um ambiente MySQL/MariaDB separado.
